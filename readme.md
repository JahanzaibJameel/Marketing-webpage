# Brooklyn Bagel Co. – Promotional HTML Page

A responsive single-page HTML document for **Brooklyn Bagel Co.**, a Croatian bakery specializing in authentic New York-style bagels. The page serves as a promotional/informational piece, likely intended for email or a simple web landing page.

The content is written in **Croatian** and includes product images, a brief company description, contact information, and a list of available bagel varieties.

---

## Features

- Fully responsive layout using inline CSS
- Centered content container (max-width 600px)
- Displays four bagel product images in a row (wraps on small screens)
- Uses Georgia / Times New Roman for a classic, serif look
- No external dependencies – pure HTML + inline CSS
- All images referenced via relative paths (must be placed in the same folder)

---

## Getting Started

To view the page locally:

1. Clone or download this repository.
2. Ensure the following image files are present in the same directory as `index.html`:
   - `Brooklyn-Bagel-Co.-Logo.png`
   - `Classic-Bagel.jpg`
   - `Sezam-Bagel.jpg`
   - `Mak-Bagel.jpg`
   - `Mix-Bagel.jpg`
3. Open `index.html` in any modern web browser.

No build tools, server, or installation steps are required.

## Customization

- **Text content**: Edit the `<p>` tags inside the `.container` div to update the promotional copy.
- **Images**: Replace the image files or update the `src` attributes in the HTML to point to new images.
- **Styling**: All CSS is contained within the `<style>` block in the `<head>`. Modify colors, fonts, spacing, etc., there.
- **Language**: The page is currently in Croatian. To switch to another language, replace the text accordingly.
