Brooklyn Bagel Co. — Simple Responsive Webpage
---------------------------------------------

Files included:
- index.html
- Brooklyn-Bagel-Co.-Logo.*
- Classic-Bagel.*
- Sezam-Bagel.*
- Mak-Bagel.*
- Mix-Bagel.*

How to use:
1. Unzip the folder.
2. Open index.html in a browser (desktop or mobile) to preview.
3. If you have real images, replace the placeholder files (matching filenames) with your real images.
4. To change the max width, edit the CSS rule in index.html:
   .container {{ max-width: 600px; }}

Notes:
- If an uploaded zip named 'Marketing E-Mail.zip' was provided, any matching images inside it were used.
- Otherwise, simple SVG placeholders were generated.

Created automatically in the environment and zipped for download.
